# 수동 감정 평가 지침

평가 기준 버전: `manual-emotions-1`. 데이터 목록 버전: `manual-catalog-10`.

현재 290곡의 2,610개 점수는 사용자의 확정 입력입니다. 대조본은 `data/manual/manual-emotions-v1.csv`이며, 쇼팽 75곡·브람스 38곡·모차르트 15곡·라흐마니노프 4곡·사티 3곡·리스트 66곡·베토벤 21악장·슈베르트 8곡·슈만 48곡·차이콥스키 《사계》 12곡입니다. 비창의 첫 세 행은 사용자가 확인한 순서대로 1·2·3악장으로 등록했습니다. 출처는 **manual**이며 EMMA 실험 평가나 EMMA 원점수로 표시하지 않습니다. EMMA와 동일한 내부 감정 차원 이름을 쓰더라도 척도·평가 구간·평가 출처는 별개입니다. 앱의 한글 감정명은 서비스에서 쓰기 위한 운영 명칭입니다.

## 평가 단위와 척도

연습곡·발라드·전주곡·엘레지·짐노페디·사랑의 꿈은 해당 곡 전체, 소나타·피아노 협주곡은 명시한 악장 전체를 평가합니다. 발췌 연주나 소나타 전체 평가를 특정 악장 평가로 바꾸지 않습니다.

1 = 거의 느껴지지 않음, 2 = 약하게 느껴짐, 3 = 분명하게 느껴짐, 4 = 강하게 느껴짐, 5 = 매우 강하게 느껴짐. 원점수는 숫자 타입의 1~5, 0.5점 단위로 저장합니다. 허용값은 `1, 1.5, 2, 2.5, 3, 3.5, 4, 4.5, 5`이며 문자열 `"4.5"`나 4.2 같은 값은 허용하지 않습니다. 기존 정수 점수와 평가 기준 버전은 그대로 유지합니다. 아홉 차원은 독립적이며 합계를 맞추거나 상위 세 감정만 평가하지 않습니다. 기존 태그나 곡의 통상적인 이미지를 이유로 확정 점수를 수정하지 않습니다.

| 내부 키 | 한글 운영 명칭 | 평가 느낌 |
| --- | --- | --- |
| wonder | 감동적인 | 감동과 경이로움 |
| transcendence | 압도적인 | 일상을 넘어서는 듯한 압도감 |
| nostalgia | 몽환적인 | 회상과 그리움이 섞인 꿈같은 느낌 |
| tenderness | 부드러운 | 다정함과 부드러움 |
| peacefulness | 평안한 | 평온함과 안정감 |
| joy | 경쾌한 | 기쁨과 경쾌함 |
| power | 힘찬 | 힘과 추진력 |
| tension | 긴장감 있는 | 긴장과 불안감 |
| sadness | 애잔한 | 슬픔과 애잔함 |

기준표의 구현은 `src/data/emotions.js`입니다. 일반 이용자는 한글 키워드를 고를 뿐, 영어 감정명이나 점수를 입력할 필요가 없습니다.

## 미평가와 새 곡 등록

2026-10-21 추가 101곡의 대조본은 `catalog-additions-2026-10-21.json`입니다. 입력의 Energy·편곡·발췌·미기재 악장/조성은 추정해서 채우지 않았습니다. 새 genre 값은 기존 `type` 필드에 등록하며 새 스키마 필드는 추가하지 않았습니다. S.216b는 S.216과 구별할 접미사 필드가 없어 보류했습니다. 조성은 제공된 제목·본문을 보존하고 기존 `musicalKeys` 파생 규칙을 유지합니다.

미평가는 `emotionScores`의 해당 키에 null로 기록하며 0·1로 채우지 않습니다. 모든 키가 숫자 타입의 1~5, 0.5점 단위일 때만 평가 완료입니다. `isValidEmotionScore`로 각 원점수를 검증하고 `isFullyRated`로 아홉 점수 전체를 검증합니다. 빠진 값이나 잘못된 값은 검토 대상으로 표시하고 점수 추천·취향 집계에서 제외합니다. 현재 별도의 점수 입력·편집 화면은 없으며 JS 데이터의 `emotionScores`에 숫자 리터럴로 입력합니다. 화면의 원점수 표시는 정수 `4`, 소수점 `4.5`를 유지합니다.

새 곡은 `src/data/manualRatings.js`에 작곡가·유형·작품번호·곡번호·악장 정보, 안정적인 ID, 정식 제목, 별도 별칭, 9개 emotionScores, ratingSource, ratingVersion, ratingUnit을 등록합니다. 작곡가·유형·작품번호·곡번호·악장을 포함한 ID를 사용하고 제목·별칭 변경으로 ID를 바꾸지 않습니다. Op.가 없는 작품은 opus를 null로 두며, S.541 같은 별도 작품목록 번호는 catalogue와 catalogueNumber로 기록합니다. Op.27-2·Op.31-2의 하위 번호는 opusPart, Op.81a의 접미사는 opusSuffix에 보존합니다. 별칭은 확인된 입력만 기록합니다. 출처와 기준 버전·평가 단위를 명시하고, 새로운 평가 체계는 별도 버전으로 관리합니다. 확정 대조 CSV와 구성 검증도 승인된 새 목록에 맞춰 갱신합니다. 현재 승인된 활성 목록은 290곡입니다.

영상은 작품·곡번호·악장·재생 구간을 확인해 별도로 등록합니다. 자동 EMMA 매칭이나 다른 작품의 영상 대체는 하지 않습니다. 공용 작곡가 이미지는 이미지 맵에서 재사용합니다. 2026-10-13 사용자 제공 기존 62곡의 최신 정보는 `catalog-update-2026-10-13.json`에 대조본을 보존하고, `manualRatings.js`의 점수·영문 제목·요약과 `manualTrackDetails.js`의 배경·감상 포인트·영상 구간에 반영했습니다. 62곡의 558개 감정 점수 중 이전 입력과 달라진 134개를 갱신했습니다. 작품 ID와 평가 척도는 유지하며, 황제 3악장과 사계 12곡은 해당 갱신 표에 포함되지 않았습니다.

## 추천과 취향 계산

파가니니 변주곡 Op.35는 단일 항목을 삭제하고 `brahms-variations-op35-book1`·`brahms-variations-op35-book2`로 분리했습니다. 각 권은 `bookNumber`를 가진 독립적인 평가·보관 단위입니다. 영상은 각각 0:00~11:26·0:00~9:38을 사용합니다. 삭제된 단일 곡의 반응을 어느 한 권에 임의로 옮기지 않으며, 작품 매칭은 권 번호까지 확인합니다.

2026-10-20 추가·수정한 74곡은 `catalog-additions-2026-10-20.json`에 입력 대조본을 보존했습니다. 소나타는 악장별로, 녹턴·소품·환상곡·변주곡은 해당 곡 전체를 평가합니다. 입력의 ‘경이로움’은 기존 `wonder` 차원에 연결하며 평가 기준은 바꾸지 않습니다. 헨델 변주곡 Op.24의 종료 시각 `26:28:00`은 사용자 확인에 따라 26분 28초로 등록하고 원문을 `originalEnd`에 보존했습니다.

2026-10-19 신규 34곡의 입력 대조본은 `catalog-additions-2026-10-19.json`입니다. 306개 점수를 추가했으며 소나타는 악장별로, 나머지는 개별 곡 전체로 평가합니다. 이후 사용자가 제공한 YouTube URL 34개를 원래 곡 순서대로 연결했습니다. `manualTrackDetails.js`의 `shortPreview`에 영상 ID를 등록하고 기존 출처·시작·종료 시각을 유지합니다.

원점수의 소수점을 유지하고, 평균·적합도·코사인 유사도는 반올림하거나 0.5점 단위로 맞추지 않습니다. 예를 들어 원점수 4.5는 0.875로 정규화됩니다. 취향 차트도 이 계산값을 사용하며 감정 성향 지수의 표시만 소수 첫째 자리까지 제공합니다. 기존 추천 방식과 가중치는 유지합니다.

저장 원점수는 1~5이며 내부 벡터는 `(s - 1) / 4`로 만든 0~1입니다. 키워드 다중 선택은 선택 차원의 평균이며 최소 하나가 3 이상인 곡을 사용합니다. 전체 후보 목록은 적합도, 선택 차원 중 3 이상 개수, 활성 취향 유사도, ID 순으로 정렬합니다. 개인화는 동점 보조 기준입니다. 느낌 추천의 대표곡은 최고 적합도 동점 후보 전체에서 동일 확률로 추첨합니다. 다중 선택에서도 최고 평균 점수로 동점인 곡은 모두 추첨 대상입니다. 기분 추천의 대표곡은 최고 원점수 평균에서 1점 이내(정규화 적합도 차이 0.25)이고 연결된 두 감정이 모두 3 이상인 곡에서 같은 확률로 추첨합니다. 기분별 직전 표시곡은 후보가 둘 이상일 때 다음 추첨에서 제외합니다. 선택 해제·초기화 후에도 이 기록은 같은 세션에서 유지하며, 새로고침하면 초기화합니다. 선택 시 난수를 갱신하며 일반 재렌더링·보관·해제·상세 조회에는 같은 대표곡을 유지합니다. 미평가 곡은 추첨하지 않습니다. 취향 추천의 코사인 정렬에는 추첨을 적용하지 않습니다. 후보가 부족하면 개수를 줄입니다.

취향은 실제로 보관한 현재 활성·평가 완료 곡만 중복 없이 정규화 평균한 9차원 벡터입니다. 미보관 추천·조회는 반영하지 않습니다. UI의 감정 성향 지수는 벡터×100이며 0~100 고정 축을 사용합니다. 선호 확률이나 감정 비율이 아니며 합계 100 조건은 없습니다. 최댓값 동점은 같은 지수의 공동 상위 감정입니다. 소수의 보관곡은 초기 취향으로 안내합니다.

취향 유사도는 같은 정규화 9차원의 코사인 유사도입니다. 0벡터나 NaN은 0으로 처리합니다. 빈 보관함·프로필 전체 0은 취향 미형성으로 처리합니다. 보관함 추천은 보관곡을 제외한 활성 목록을 유사도로 정렬하며 모두 보관하면 빈 결과입니다. 보관·해제와 새로고침 시 저장된 보관 ID에서 다시 계산합니다.
