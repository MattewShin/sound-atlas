# 수동 감정 평가 지침

평가 기준 버전: `manual-emotions-1`. 데이터 목록 버전: `chopin-36-emotions-1`.

현재 36곡의 324개 점수는 사용자의 확정 입력입니다. 출처는 **manual**이며 EMMA 실험 평가나 EMMA 원점수로 표시하지 않습니다. EMMA와 동일한 내부 감정 차원 이름을 쓰더라도 척도·평가 구간·평가 출처는 별개입니다. 앱의 한글 감정명은 서비스에서 쓰기 위한 운영 명칭입니다.

## 평가 단위와 척도

연습곡·발라드는 해당 작품 전체, 소나타는 명시한 악장 전체를 평가합니다. 발췌 연주나 소나타 전체 평가를 특정 악장 평가로 바꾸지 않습니다.

1 = 거의 느껴지지 않음, 2 = 약하게 느껴짐, 3 = 분명하게 느껴짐, 4 = 강하게 느껴짐, 5 = 매우 강하게 느껴짐. 정수 1~5로 저장합니다. 아홉 차원은 독립적이며 합계를 맞추거나 상위 세 감정만 평가하지 않습니다. 기존 태그나 곡의 통상적인 이미지를 이유로 확정 점수를 수정하지 않습니다.

| 내부 키 | 한글 운영 명칭 | 평가 느낌 |
| --- | --- | --- |
| wonder | 감동적인 | 감동과 경이로움 |
| transcendence | 압도적인 | 일상을 넘어서는 듯한 압도감 |
| nostalgia | 몽환적인 | 회상과 그리움이 섞인 꿈같은 느낌 |
| tenderness | 부드러운 | 다정함과 부드러움 |
| peacefulness | 평안한 | 평온함과 안정감 |
| joy | 경쾌한 | 기쁨과 경쾌함 |
| power | 힘찬 | 힘과 추진력 |
| tension | 긴장감 있는 | 긴장과 불안감 |
| sadness | 애잔한 | 슬픔과 애잔함 |

기준표의 구현은 `src/data/emotions.js`입니다. 일반 이용자는 한글 키워드를 고를 뿐, 영어 감정명이나 점수를 입력할 필요가 없습니다.

## 미평가와 새 곡 등록

미평가는 `emotionScores`의 해당 키에 null로 기록하며 0·1로 채우지 않습니다. 모든 키가 정수 1~5일 때만 평가 완료입니다. 빠진 값은 검토 대상으로 표시하고 점수 추천·취향 집계에서 제외합니다.

새 곡은 `src/data/manualRatings.js`에 작곡가·유형·작품번호·곡번호·악장 정보, 안정적인 ID, 정식 제목, 별도 별칭, 9개 emotionScores, ratingSource, ratingVersion, ratingUnit을 등록합니다. 작곡가·유형·작품번호·곡번호·악장을 포함한 ID를 사용하고 제목·별칭 변경으로 ID를 바꾸지 않습니다. 별칭은 확인된 입력만 기록합니다. 출처와 기준 버전·평가 단위를 명시하고, 새로운 평가 체계는 별도 버전으로 관리합니다. 확정 대조 CSV와 구성 검증도 승인된 새 목록에 맞춰 갱신합니다. 현재 승인된 활성 목록은 36곡입니다.

영상은 작품·곡번호·악장·재생 구간을 확인해 별도로 등록합니다. 자동 EMMA 매칭이나 다른 작품의 영상 대체는 하지 않습니다. 공용 작곡가 이미지는 이미지 맵에서 재사용합니다.

## 추천과 취향 계산

저장 원점수는 1~5이며 내부 벡터는 `(s - 1) / 4`로 만든 0~1입니다. 키워드 다중 선택은 선택 차원의 평균이며 최소 하나가 3 이상인 곡을 사용합니다. 적합도, 선택 차원 중 3 이상 개수, 활성 취향 유사도, ID 순으로 정렬합니다. 개인화는 동점 보조 기준입니다. 후보가 부족하면 개수를 줄이며 무작위 보정은 하지 않습니다.

취향은 실제로 보관한 현재 활성·평가 완료 곡만 중복 없이 정규화 평균한 9차원 벡터입니다. 미보관 추천·조회는 반영하지 않습니다. UI의 감정 성향 지수는 벡터×100이며 0~100 고정 축을 사용합니다. 선호 확률이나 감정 비율이 아니며 합계 100 조건은 없습니다. 최댓값 동점은 같은 지수의 공동 상위 감정입니다. 소수의 보관곡은 초기 취향으로 안내합니다.

취향 유사도는 같은 정규화 9차원의 코사인 유사도입니다. 0벡터나 NaN은 0으로 처리합니다. 빈 보관함·프로필 전체 0은 취향 미형성으로 처리합니다. 보관함 추천은 보관곡을 제외한 활성 목록을 유사도로 정렬하며 모두 보관하면 빈 결과입니다. 보관·해제와 새로고침 시 저장된 보관 ID에서 다시 계산합니다.
