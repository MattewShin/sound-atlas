# 과거 EMMA 참고 자료

이 폴더는 앱과 분리된 참고 자료입니다. 앱은 이 자료를 import하지 않습니다.

- 기존 원본 CSV `EMMA__filtered_2026-10-07.csv`는 새 수동 평가 자료로 교체할 예정이라는 사용자 요청에 따라 프로젝트에서 삭제했습니다.
- `emmaReference.json`: 원본 문자열, EMMA 원점수, 출처, 연주 구간. 곡 연결 후보와 태그 제안은 포함하지 않습니다.
- `importErrors.json`: 검증 오류와 원본 행. 오류 문자를 추정 복구하지 않습니다.
- `archive/`: 교체 전 20곡에 대한 매칭·태그 제안·사람의 검토 기록. 과거 참고 기록이며 현재 활성 평가로 사용하지 않습니다.

EMMA 형식의 파일을 다시 참고 자료로 가져오려면 `npm run import:emma -- <EMMA CSV 경로>`를 사용합니다. 이 명령은 EMMA 전용 검증 도구이며, 새 사용자 수동 평가 파일을 활성 목록에 반영하는 명령이 아닙니다. 가져오기는 활성 목록·수동 점수·보관 기록·영상에 영향을 주지 않습니다. 원본 점수의 null과 0은 별개이며, EMMA 발췌 구간 평가를 곡 전체나 다른 악장에 일반화하지 않습니다. CSV 영상 ID는 앱 재생 링크로 복사하지 않습니다.

현재 44곡은 `data/manual/manual-emotions-v1.csv`의 사용자 확정 **manual** 평가입니다. 감정 차원 이름이 같아도 EMMA 실험 평가가 아닙니다.
