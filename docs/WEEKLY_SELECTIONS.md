# 주간 소개 운영

운영자가 수정할 파일은 `src/data/weeklySelections.js`입니다. 첫 글은 입력된 문구로 등록되어 있으며 `published: true`, 한국 시간 2026-10-14~2026-10-31에 홈에 표시됩니다. `chopin-etude-op25-no1`의 기존 곡 상세·이미지·미리듣기와 보관함을 공유합니다.

## 글 추가·수정

배열 안에 객체를 추가하고 다음 항목을 입력한 뒤 기존 배포 방식으로 변경 사항을 배포하세요.

| 항목 | 내용 |
| --- | --- |
| `id` | 글마다 다른 고유 ID. 같은 곡의 재선정에도 새 ID 사용 |
| `trackId` | `src/data/manualRatings.js`의 기존 곡 ID |
| `title`, `teaser` | 소개 제목과 홈 한 줄 소개 |
| `reason`, `audience` | 내가 고른 이유와 추천 대상. 필수 입력 |
| `sectionName` | 생략하거나 비우면 “이번 주의 한 곡” |
| `editorName` | 선택 항목. 비우면 선정자 이름 숨김 |
| `listeningMoment` | 선택적인 구간 감상 설명. 비우면 생략 |
| `previewRange` | 선택적인 재생 구간. 기본값 `null` |
| `startsOn`, `endsOn` | `YYYY-MM-DD` 형식, 시작일·종료일 포함 |
| `published` | `true`일 때만 공개. 초안·개발 예시는 `false` |

별도 구간을 사용할 때:

```js
previewRange: {
  videoId: '8VbA0_VvWgQ', // 해당 곡의 기존 shortPreview.videoId
  start: '0:30',
  end: '1:10',
},
```

`분:초` 형식이며 초는 00~59, 종료는 시작보다 커야 합니다. 영상 ID가 기존 곡의 영상과 다르거나 시간이 잘못되면 기존 구간으로 돌아갑니다. 기존 영상이 없으면 소개 글·보관하기·곡 상세만 제공됩니다. 영상은 “미리듣기 열기”를 눌러야 불러오고 자동 재생하지 않습니다.

첫 글의 `listeningMoment`와 `previewRange`는 미입력 상태입니다. 구간 설명은 생략하고 기존 영상의 0:00~2:10을 사용합니다.

## 노출과 지난 글

한국 날짜는 `Asia/Seoul`을 명시해 서버와 브라우저 모두 동일하게 판단합니다. 공개 글 중 현재 기간에 해당하는 하나를 표시하며, 기간이 겹치면 가장 최근 시작일을 우선합니다. 같은 시작일은 글 ID 내림차순으로 결정합니다. 개발 모드 콘솔에서 잘못된 입력과 기간 겹침을 안내합니다.

미래 글과 비공개 글은 홈·지난 선정곡·읽을 수 있는 글에서 제외됩니다. 필수 정보가 없거나 곡 ID·날짜가 잘못된 공개 글도 제외됩니다. 현재 글이 없으면 주간 소개 섹션을 숨기고, 지난 글이 있으면 작은 지난 선정곡 링크를 제공합니다. 지난 글은 종료일 최신순으로 표시합니다.

이전 글을 삭제하거나 덮어쓰지 않으면 당시 제목과 선정 이유가 보존됩니다. 같은 곡을 재선정할 때 새 객체를 추가하세요. 예약 전환은 화면을 불러올 때 판단하며, 열린 화면에서도 기존 날짜 갱신·화면 복귀 흐름에 반영됩니다. 별도 스케줄러는 없습니다.

## 구현과 검증

- 홈: 기존 추천곡 영역 전체 아래에 가로형 소개와 지난 선정곡 링크.
- 소개 글·지난 글: 앱의 기존 화면 상태 방식, 곡 상세는 기존 모달.
- `src/data/weeklySelectionHelpers.js`: 한국 날짜, 입력 검증, 노출·정렬, 미리듣기 구간 선택.
- `src/components/WeeklySelectionScreens.jsx`: 홈 소개·소개 글·지난 글 화면.
- `src/App.jsx`, `src/styles.css`: 기존 기능과 연결, 반응형 디자인.
- `src/data/weeklySelections.test.js`, `scripts/weeklySelectionDomTest.mjs`, `scripts/test.mjs`: 기존 Node 테스트·실제 JSX/React DOM 검증에 통합.

`npm test`와 `npm run build`로 검증합니다. 이번 작업에서 전체 테스트 110개와 프로덕션 빌드가 통과했습니다. 날짜 경계·공개 상태·겹침·잘못된 입력·영상 유무·사용자 구간과 기본 구간·화면 이동·보관 상태 동기화를 자동 검증합니다. 작은 화면의 소개 제목·한 줄 소개는 각각 두 줄로 제한하고 곡명은 줄바꿈해 유지합니다. 실제 모바일·데스크톱 시각 검증은 사용자가 직접 확인하기로 했습니다. 영상의 실제 외부 재생은 자동 검증 범위에 포함되지 않습니다.
