# Classic Atlas

듣고 싶은 한글 감정 키워드나 현재 기분으로 피아노 음악을 탐색하고, 마음에 남는 곡을 보관하는 React 19 + Vite 6 앱입니다.

활성 목록은 총 44곡입니다. 쇼팽 36곡(Op.10·Op.25 연습곡 각 12곡, 소나타 No.2 Op.35·No.3 Op.58의 각 4악장, 발라드 4곡), 라흐마니노프 4곡(전주곡 Op.23 No.1·5, 엘레지 Op.3 No.1, 전주곡 Op.3 No.2), 사티 짐노페디 No.1~3, 리스트 사랑의 꿈 No.3 S.541을 사용합니다. 각 소나타 악장은 독립적인 추천·보관 단위입니다.

## 실행과 검증

```sh
npm install
npm run dev
npm test
npm run build
npm run diagnose:recommendations
```

`npm test`는 확정 CSV의 396개 점수 대조, 추천 순위·동점·미평가, 취향 프로필·코사인 유사도, 36곡에서 44곡으로의 저장 상태 확장, 실제 JSX 컴파일과 서버 렌더링을 확인합니다. 서버 렌더링은 실브라우저의 모바일 잘림·클릭 검증을 대신하지 않습니다.

## 감정과 추천

감정의 순서·내부 키·한글 운영 명칭은 `src/data/emotions.js`가 단일 기준입니다. 화면에서 감동적인, 압도적인, 몽환적인, 부드러운, 평안한, 경쾌한, 힘찬, 긴장감 있는, 애잔한을 고릅니다. 느낌 선택은 최대 3개이며 동일 가중치입니다. 기분 선택은 `src/data/feelingSuggestions.js`의 별도 제품 정책으로 즉시 감정 키에 연결합니다. 추가 키워드·강도 선택 단계는 없습니다.

원점수 1~5를 `(s - 1) / 4`로 정규화합니다. 선택 감정의 평균 점수로 정렬하며, 선택 감정 중 하나 이상이 3 이상인 곡만 추천합니다. 후보가 부족하면 결과 개수를 줄입니다. 동점은 3 이상인 선택 감정 개수, 활성 개인화 유사도, 안정적인 ID 순서로 해소합니다. 개인화는 서로 다른 적합도를 뒤집지 않습니다. 기본 키워드 화면은 개인화하지 않으며 내 취향 추천은 별도 전환으로 제공합니다. 무작위 순서는 사용하지 않습니다.

## 보관함과 나의 취향

실제로 보관한 활성·평가 완료 곡만 중복 없이 사용합니다. 감정별 정규화 평균의 9차원 벡터가 취향 프로필입니다. 보관곡 1개부터 0이 아닌 프로필이 활성화되고, 3곡 미만이면 초기 취향으로 안내합니다. 감정 성향 지수는 프로필×100이며 차트는 0~100 고정 축입니다. 비율이나 확률이 아니며 합계가 100일 필요가 없습니다. 상위 감정 동점은 공동으로 표시합니다. 빈 보관함과 0벡터는 미형성 상태이며 차트·취향 추천을 만들지 않습니다.

내 취향 추천은 같은 9차원 벡터의 코사인 유사도로 정렬하고 이미 보관한 곡을 제외합니다. 모두 보관하면 빈 결과를 안내합니다. 키워드 추천으로 돌아갈 수 있으며 보관·해제 때와 새로고침 때 새 점수로 프로필을 계산합니다. 추천이나 상세 조회는 취향의 입력이 아닙니다. 취향 화면에는 현재 활성 목록의 곡 수와 작곡가를 안내합니다.

## 데이터 관리

- `src/data/manualRatings.js`: 확정 수동 평가 44곡. `ratingSource: manual`, `ratingVersion: manual-emotions-1`.
- `data/manual/manual-emotions-v1.csv`: 사용자가 제공한 확정 입력 대조본. 작곡가 확장에 맞춰 기존 `chopin-emotions-v1.csv`를 이름 변경했습니다.
- `src/data/musicData.js`: 활성 목록·공용 이미지 맵·상세·구 ID 매핑. 별칭은 제목과 별도로 다음 줄에 표시합니다.
- `src/data/recommendations.js`: 점수 추천·취향 프로필·코사인 유사도.
- `src/data/storage.js`: 음악 저장 상태만 버전별 정리.
- `data/emma/`: 앱과 분리된 과거 EMMA 검증 참고 자료. 원본 CSV는 사용자 요청으로 삭제했으며, `archive/`는 교체 전 매칭·검토 기록입니다.
- `data/manual/legacy-media.json`: 활성 목록에서 제외된 영상 등록 참고본. 앱은 읽지 않습니다.
- [평가 지침](data/manual/rating-guide.md): 점수 정의와 신규 곡 등록 방법.

대표 키워드는 3 이상인 감정 중 점수 상위 최대 3개이며 동점은 기준표 순서입니다. 전체 감정 점수는 상세에서 표시합니다. 미평가는 null로 두고 검토 대상으로 표시하며 추천과 취향 집계에서 제외합니다. EMMA 가져오기 도구는 참고 자료만 갱신하며 수동 평가를 변경하거나 곡을 자동 매칭하지 않습니다.

작곡가 이미지는 `composerImages`에서 기존 `/composers/`의 쇼팽·라흐마니노프·사티·리스트 파일을 카드·상세·보관함에 공유합니다. 영상은 작품번호·곡번호·악장이 정확히 같은 등록만 재사용합니다. 현재 활성 44곡에 대응하는 기존 등록 영상은 없으므로 미리듣기 준비 중 상태입니다. 추후 `trackDetails[id].shortPreview`에 `provider: youtube`, `videoId`, 초 단위 `startSeconds`, `endSeconds`, `sourceLabel`을 추가하면 기존 플레이어를 사용할 수 있습니다.

## 로컬 저장 마이그레이션

`classic-atlas-track-reactions-v1`의 `listenAgain` 보관 상태와 `liked` 기록을 사용합니다. 데이터 버전 `manual-catalog-2`는 `classic-atlas-music-data-version`에 저장합니다. 기존 `chopin-36-emotions-1`의 36곡 ID와 보관·좋아요·선택은 유지합니다. 더 오래된 구 ID는 정확한 두 쇼팽 악장과 라흐마니노프 Op.23 No.5, 사티 짐노페디 No.1, 리스트 사랑의 꿈 No.3만 명시적으로 연결합니다. 구 라흐마니노프 Op.3의 잘못된 곡번호는 추정 매칭하지 않습니다. 이미 삭제된 보관 기록을 복구하지는 않습니다. 다른 구 곡 참조는 제거하며 인증·다른 설정은 보존합니다.

선택값은 `classic-atlas-music-selection-v1`에 감정 키로 저장합니다. 유효한 키·현재 한글명은 유지하고 이전 편안한만 평안한으로 변환합니다. 따뜻한·장엄한 등으로 새 평가를 추정하지 않습니다. 최근 곡 키 `classic-atlas-recent-tracks-v1`이 있으면 ID 매핑·중복 제거를 적용합니다. 과거 취향·강도·추천 캐시 키만 폐기합니다. 정리된 보관곡이 있으면 한 번 안내하며 동일 버전 재실행은 추가 삭제를 하지 않습니다. `localStorage.clear()`는 사용하지 않습니다.

로그인·서버 DB·외부 음원 API·실제 공연 예매는 현재 범위에 포함되어 있지 않습니다.
