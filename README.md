# Classic Atlas

듣고 싶은 한글 감정 키워드나 현재 기분으로 피아노 음악을 탐색하고, 마음에 남는 곡을 보관하는 React 19 + Vite 6 앱입니다.

활성 목록은 총 291곡입니다. 쇼팽 75곡(기존 54곡과 녹턴 21곡), 브람스 38곡(소나타 13악장, 랩소디 2곡, Op.116·117·118 소품 16곡, 변주곡 7곡), 모차르트 15곡(변주곡 13곡과 환상곡 2곡), 라흐마니노프 4곡, 사티 3곡, 리스트 67곡, 베토벤 21악장, 슈베르트 8곡, 슈만 48곡, 차이콥스키 《사계》 12곡으로 구성됩니다. 소나타는 악장별로, 소품과 변주곡은 각 작품 전체를 추천·보관합니다. 사용자 제공 제목·감정 점수·요약·감상 설명을 반영했습니다.

## 실행과 검증

```sh
npm install
npm run dev
npm test
npm run build
npm run diagnose:recommendations
```

`npm test`는 확정 CSV의 2,619개 점수 대조, 추천 순위·동점·미평가, 취향 프로필·코사인 유사도, 이전 목록 버전의 저장 상태 보존, 영상 등록 구간 재사용, 추천 카드 8개 제한·전체 목록 20곡 단위 표시·순위 유지·중복 방지·마지막 페이지, 실제 JSX 컴파일과 서버 렌더링을 확인합니다. 서버 렌더링은 실브라우저의 모바일 잘림·클릭 검증을 대신하지 않습니다.

## 모바일 홈 화면에 설치

운영 사이트는 PWA로 제공됩니다. iPhone/iPad Safari에서는 공유 버튼의 **홈 화면에 추가**, Android Chrome에서는 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 설치하면 `Piano Mood` 아이콘으로 홈 화면에서 standalone 실행됩니다.

Service Worker는 정적 화면 자산과 오프라인 안내만 캐시합니다. `/api/` 공연 요청, 외부 포스터·예매 링크와 사용자 데이터는 Service Worker 캐시에 저장하지 않습니다. 네트워크가 없을 때 공연이나 추천 결과를 오래된 정상 응답으로 위장하지 않고 연결 확인 화면을 표시합니다.

## 감정과 추천

감정의 순서·내부 키·한글 운영 명칭은 `src/data/emotions.js`가 단일 기준입니다. 화면에서 감동적인, 압도적인, 몽환적인, 부드러운, 평안한, 경쾌한, 힘찬, 긴장감 있는, 애잔한을 고릅니다. 느낌 선택은 최대 3개이며 동일 가중치입니다. 기분 선택은 `src/data/feelingSuggestions.js`의 별도 제품 정책으로 즉시 감정 키에 연결합니다. 느낌·기분은 각각 선택을 유지하고, 선택 초기화는 현재 탭의 선택만 지우며 탭을 바꾸지 않습니다. 선택한 느낌·기분을 다시 누르면 해제합니다. 해제 후 다시 선택하면 해당 조건으로 대표곡을 새로 추첨합니다. 추가 키워드·강도 선택 단계는 없습니다.

원점수 1~5를 `(s - 1) / 4`로 정규화합니다. 선택 감정의 평균 점수로 정렬하며, 선택 감정 중 하나 이상이 3 이상인 곡을 전체 추천 목록에 포함합니다. 후보가 부족하면 결과 개수를 줄입니다. 전체 후보 목록의 동점은 3 이상인 선택 감정 개수, 활성 개인화 유사도, 안정적인 ID 순서로 해소합니다. **느낌으로 시작하기**의 대표곡은 최고 평균 점수의 동점 후보 전체에서 무작위로 한 곡을 선택합니다. 단독 최고점 곡이 있으면 그 곡을 유지합니다. **기분에서 시작하기**의 대표곡은 최고 원점수 평균에서 1점 이내이고 연결된 두 감정이 각각 3 이상인 곡을 같은 확률로 추첨합니다. 기분별 직전 표시곡을 기억해 다음 추첨에서 제외하며, 후보가 하나뿐이면 그 곡을 사용합니다. 현재 기분별 후보는 기쁜·설레는 각 41곡, 차분한 49곡, 울적한 64곡, 답답한 30곡, 화나는 68곡입니다. 선택 해제·초기화·탭 전환에도 직전 기분 추천 기록을 유지하고 새로고침하면 초기화합니다. 느낌·기분을 선택할 때 다시 추첨하고 보관·해제·상세 조회 같은 일반 화면 갱신에는 대표곡을 유지합니다. 새로고침하면 선택부터 초기화됩니다. 기본 추천 화면은 개인화하지 않으며 내 취향 추천은 별도 전환으로 제공합니다.

## 보관함과 나의 취향

메인 화면은 대표곡 1개와 대표곡을 제외한 추천 순위 상위 최대 8곡을 가로 카드로 표시합니다. ‘추천곡 더 보기’는 대표곡을 포함한 전체 추천 목록으로 이동합니다. 전체 목록은 같은 추천 순서로 처음 20곡을 표시하고 ‘더 불러오기’로 다음 20곡씩 추가합니다. 이미 표시된 곡은 중복되지 않으며 마지막에는 불러오기 버튼을 숨깁니다. 키워드·기분·추천 방식이 바뀌거나 내 취향의 보관 기준이 바뀌면 표시 개수는 20곡부터 다시 시작합니다. 전체 목록에서 곡 상세·영상·보관 기능을 사용할 수 있으며 목록을 열거나 추가로 불러오는 동작은 대표곡을 다시 추첨하지 않습니다.

실제로 보관한 활성·평가 완료 곡만 중복 없이 사용합니다. 감정별 정규화 평균의 9차원 벡터가 취향 프로필입니다. 보관곡 1개부터 0이 아닌 프로필이 활성화되고, 3곡 미만이면 초기 취향으로 안내합니다. 감정 성향 지수는 프로필×100이며 차트는 0~100 고정 축입니다. 비율이나 확률이 아니며 합계가 100일 필요가 없습니다. 상위 감정 동점은 공동으로 표시합니다. 빈 보관함과 0벡터는 미형성 상태이며 차트·취향 추천을 만들지 않습니다.

내 취향 추천은 같은 9차원 벡터의 코사인 유사도로 정렬하고 이미 보관한 곡을 제외합니다. 모두 보관하면 빈 결과를 안내합니다. 키워드 추천으로 돌아갈 수 있으며 보관·해제 때와 새로고침 때 새 점수로 프로필을 계산합니다. 추천이나 상세 조회는 취향의 입력이 아닙니다. 취향 화면에는 현재 활성 목록의 곡 수와 작곡가를 안내합니다.

## 데이터 관리

2026-10-21 입력 102곡(슈만 36곡·리스트 66곡)을 모두 추가했습니다. 중복은 없습니다. 보류했던 메피스토 왈츠 No.4 S.216b는 2026-10-22 사용자 확인에 따라 별도 작품으로 등록했으며, 기존 catalogueNumber 필드에 `216b`를 보존합니다. 이 후속 추가에서도 기존 251개 작품의 개별 identity hash는 모두 유지됩니다. S.216b 후속 검증은 [등록 보고](docs/CATALOG_ADDITION_2026-10-22.md), 전체 ID·매핑·읽기 전용 검증은 [카탈로그 추가 보고](docs/CATALOG_ADDITION_2026-10-21.md)에 있습니다.

공연 찾기는 선택곡 없이 KOPIS 서양음악(클래식) 공연을 날짜·지역으로 탐색합니다. 기본 기간은 오늘부터30일, 기본 지역은 마지막 선택값(없으면 서울)입니다. 목록20건씩 추가 로딩, 공연명·공연장 검색, 독립 공연 상세·소개 이미지·예매 링크를 제공합니다. 음악 추천·보관함·나의 취향은 기존대로 유지합니다. [공연 탐색 설계](docs/CONCERT_BROWSER.md), [서버 설정](docs/KOPIS_SETUP.md)을 참고하세요.

Brasch의 초상 사진](https://commons.wikimedia.org/wiki/File:JohannesBrahms1.jpg)을 800×600으로 가공했습니다(Commons의 public domain 표기). 영상은 정확히 같은 작품·곡번호·악장에만 연결합니다. 전체 291곡에 사용자 제공 유튜브 영상·재생 구간을 연결했습니다. 신규 34곡의 링크는 사용자가 지정한 원래 곡 순서대로 반영했습니다. 영상·연주자·채널·종료 시각은 사용자 입력 그대로 반영했으며, 외부 메타데이터나 실제 청취로 별도 검증하지 않았습니다.

## 로컬 저장 마이그레이션

파가니니 변주곡 Op.35는 제1권·제2권을 독립된 곡 ID로 관리합니다. `bookNumber`로 권을 구분하며 음악 추천·보관에서도 독립된 곡입니다. 이전 단일 항목 `brahms-variations-op35`는 활성 목록에서 제거했고, 해당 항목의 보관·좋아요는 새 권별 항목으로 자동 이전하지 않습니다.

`classic-atlas-track-reactions-v1`의 `listenAgain` 보관 상태와 `liked` 기록을 사용합니다. 데이터 버전 `manual-catalog-11`는 `classic-atlas-music-data-version`에 저장합니다. 기존 목록 버전의 ID와 보관·좋아요는 유지합니다. 키워드 선택은 현재 화면에서만 유지하고 새로고침하면 초기화합니다. 이전 `classic-atlas-music-selection-v1` 저장값은 앱 시작 시 제거합니다. 더 오래된 구 ID는 정확한 두 쇼팽 악장과 라흐마니노프 Op.23 No.5, 사티 짐노페디 No.1, 리스트 사랑의 꿈 No.3, 베토벤 월광 1·3악장·발트슈타인 1악장·열정 3악장을 명시적으로 연결합니다. 구 라흐마니노프 Op.3의 잘못된 곡번호는 추정 매칭하지 않습니다. 이미 삭제된 보관 기록을 복구하지는 않습니다. 다른 구 곡 참조는 제거하며 인증·다른 설정은 보존합니다.

선택값은 `classic-atlas-music-selection-v1`에 감정 키로 저장합니다. 유효한 키·현재 한글명은 유지하고 이전 편안한만 평안한으로 변환합니다. 따뜻한·장엄한 등으로 새 평가를 추정하지 않습니다. 최근 곡 키 `classic-atlas-recent-tracks-v1`이 있으면 ID 매핑·중복 제거를 적용합니다. 과거 취향·강도·추천 캐시 키만 폐기합니다. 정리된 보관곡이 있으면 한 번 안내하며 동일 버전 재실행은 추가 삭제를 하지 않습니다. `localStorage.clear()`는 사용하지 않습니다.

실제 예매는 KOPIS가 제공한 외부 예매처 링크로 이동합니다. 서버 전용 KOPIS_SERVICE_KEY를 사용하며 브라우저에 전달하지 않습니다. 개발은 npm run dev, 운영은 npm run build 후 npm start로 실행합니다. Vercel은 api/index.js와 vercel.json의 같은 GET 전용 API를 사용합니다. 자동 수집·OCR·판정용 배치를 새로 두지 않습니다.

지역은 classic-atlas-concert-region-v1에 저장합니다. 곡 ID·보관 기록·음악 저장 마이그레이션은 변경하지 않습니다.
