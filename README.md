# Classic Atlas

감정과 에너지에 따라 클래식 피아노 곡을 탐색하고, 마음에 남는 곡을 보관할 수 있는 React + Vite 웹 애플리케이션입니다.

현재는 실제 음원·공연 데이터 없이도 곡의 분위기, 감상 포인트, 짧은 영상 하이라이트를 중심으로 클래식 입문 경험을 제공하는 데 초점을 둡니다.

## 주요 기능

### 감정·에너지 기반 곡 탐색

- 8가지 감정(MOOD)을 최대 3개까지 선택할 수 있습니다.
- 에너지(차분하게 · 적당히 · 강렬하게)를 선택할 수 있습니다.
- 선택한 모든 감정이 포함된 곡을 먼저 찾고, 없으면 하나 이상 일치하는 곡으로 범위를 넓힙니다.
- 에너지가 정확히 일치하는 후보가 있으면 그 곡을 우선 사용하며, 없을 때만 감정이 맞는 다른 에너지의 곡을 보여줍니다.
- 아무 조건도 선택하지 않은 시작 화면에서는 `처음 듣기 좋은 곡`과 빠른 시작 버튼을 제공합니다.

### 추천 방식 선택

- **지금의 기분**: 기본 추천 방식입니다. 현재 선택한 감정·에너지만 반영하며 보관함 정보는 사용하지 않습니다.
- **내 취향**: 보관함에 3곡 이상 담았을 때 활성화됩니다. 현재 선택한 조건을 우선 유지하면서, 보관 곡에서 자주 나타난 분위기와 에너지를 동점 정렬의 보조 기준으로 사용합니다.
- 내 취향 모드에서는 이미 보관한 곡을 우선 제외해 비슷한 새 곡을 발견할 수 있게 합니다. 제외 후 후보가 비면 기존 결과를 그대로 사용합니다.

### 곡 상세와 감상 하이라이트

- 추천 카드와 보관함 카드를 누르면 전체 화면형 바텀시트로 곡 상세를 볼 수 있습니다.
- 작곡가 이미지, 작품·악장 정보, 감정·에너지 태그, 추천 이유, 곡 설명, 감상 팁, 한 장면 하이라이트를 제공합니다.
- 영상 하이라이트가 등록된 곡은 YouTube iframe 기반의 세로형 감상 화면을 열 수 있습니다.
- 영상 데이터가 없는 곡은 준비 중 안내를 표시합니다.

### 보관함

- 상세 화면 또는 홈 대표 카드에서 곡을 보관하거나 해제할 수 있습니다.
- 보관함에서는 보관한 곡을 최신순으로 확인하고, 곡 상세 열기 및 개별 보관 해제를 할 수 있습니다.
- 보관 상태는 브라우저 `localStorage`에 저장되어 새로고침 후에도 유지됩니다.

### 공연 찾기 안내

- 하단 `공연 찾기` 탭에는 향후 제공할 공연 기능을 소개하는 오픈 예정 화면이 있습니다.
- 실제 공연 목록, 예매 링크, 외부 공연 API는 아직 연결하지 않았습니다.

## 기술 스택

- React 19
- Vite 6
- CSS (외부 UI 라이브러리 없음)
- Browser `localStorage`

## 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령으로 확인합니다.

```bash
npm run build
```

## 데이터 구조

곡 기본 데이터는 `src/data/musicData.js`의 `tracks`에서 관리합니다.

```js
{
  id: 'beethoven-moonlight-1',
  composer: '베토벤',
  title: '피아노 소나타 14번 「월광」',
  movement: '1악장',
  moods: ['애잔한', '긴장감 있는', '장엄한'],
  energy: '차분하게',
}
```

- `moods`는 `편안한`, `따뜻한`, `애잔한`, `설레는`, `몽환적인`, `경쾌한`, `장엄한`, `긴장감 있는`만 사용합니다.
- `energy`는 `차분하게`, `적당히`, `강렬하게` 중 하나입니다.
- `cardDetails`는 카드의 색상·문구·태그 등 보조 정보를 `tracks`와 같은 순서로 관리합니다.
- `trackDetails`는 곡 ID를 키로 사용하며, 상세 설명·하이라이트·작곡가 이미지·영상 정보를 관리합니다.

### 영상 하이라이트 등록

`trackDetails`의 해당 곡 ID에 `shortPreview`를 추가하면 상세 화면에서 영상 감상 버튼이 활성화됩니다.

```js
shortPreview: {
  provider: 'youtube',
  videoId: 'YouTube video ID',
  startSeconds: 7,
  endSeconds: 339,
  sourceLabel: '연주자 · 출처',
}
```

시간은 `mm:ss`가 아닌 영상 전체 기준의 초 단위 숫자로 입력합니다.

## 로컬 저장 데이터

보관함은 아래 키를 사용합니다.

```text
classic-atlas-track-reactions-v1
```

각 곡은 `listenAgain: true`일 때 보관함에 표시됩니다. 이전 버전의 `liked`, `concertWish` 값이 남아 있어도 현재 화면과 추천에는 사용하지 않습니다.

## 프로젝트 구조

```text
src/
├── App.jsx              # 화면, 상태, 탭 전환, 보관함 연결
├── styles.css           # 앱 전체 스타일
└── data/
    └── musicData.js     # 곡·카드·상세·추천 로직 데이터

public/
└── composers/           # 작곡가 카드 및 상세 이미지
```

## 현재 범위와 향후 계획

현재 프로젝트는 로컬 데이터와 브라우저 저장소만 사용합니다. 로그인, 서버 DB, 외부 음원 API, 실제 공연 데이터·예매, 개인 계정 간 동기화는 아직 구현하지 않았습니다.
