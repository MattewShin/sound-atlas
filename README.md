# Classic Atlas

주간 소개 콘텐츠는 `src/data/weeklySelections.js`에서 관리합니다. 글 등록·기간·공개 여부·미리듣기 구간 설정은 [주간 소개 운영 안내](docs/WEEKLY_SELECTIONS.md)를 참고하세요.

홈의 초기 탐색 카드 선정 방식과 교체 시점, 로그인 연동 지점은 [홈 탐색 카드 안내](docs/HOME_DISCOVERY.md)를 참고하세요.

KOPIS 공연정보·이미지 URL을 Supabase에 수동 수집하는 설정과 실행 순서는 [공연 수집 1단계](docs/CONCERT_COLLECTION.md)를 참고하세요.

수집한 상세 이미지를 로컬 EasyOCR로 판독하고 결과를 저장하는 방법은 [EasyOCR 배치 2단계](docs/EASYOCR_BATCH.md)를 참고하세요.

저장된 OCR의 프로그램 구간·작품 후보·근거 저장과 단건 수동 검토는 [프로그램 분석 3단계](docs/PROGRAM_ANALYSIS.md)를 참고하세요. 먼저 특정 공연 dry-run과 원본 이미지를 확인하고 신규 마이그레이션을 적용합니다.

웹 검색·수집·OCR의 진입점과 공통 모듈 역할은 [공연 코드 구조](docs/CONCERT_PIPELINE.md)에 정리했습니다.

기존 검색을 기본으로 유지하면서 저장된 유효한 확정 결과만 검색하는 방법은 [Supabase 공연 검색 미리보기](docs/SUPABASE_CONCERT_PREVIEW.md)를 참고하세요. 서버 전용 `CONCERT_SEARCH_BACKEND=supabase`로 선택합니다.

지난 공연 정리 → 수집 → EasyOCR → 신규 분석 저장을 한 번에 실행하고 Windows 정기 실행을 준비하는 방법은 [로컬 통합 배치](docs/LOCAL_PIPELINE.md)를 참고하세요. [지난 공연 삭제 안내](docs/EXPIRED_CONCERT_CLEANUP.md)의 신규 SQL을 적용하고 `npm run pipeline -- plan`으로 확인하세요. run은 한국 시간 어제까지 종료된 공연과 종속 자료를 실제 삭제합니다.

듣고 싶은 한글 감정 키워드나 현재 기분으로 피아노 음악을 탐색하고, 마음에 남는 곡을 보관하는 React 19 + Vite 6 앱입니다.

활성 목록은 총 291곡입니다. 쇼팽 75곡(기존 54곡과 녹턴 21곡), 브람스 38곡(소나타 13악장, 랩소디 2곡, Op.116·117·118 소품 16곡, 변주곡 7곡), 모차르트 15곡(변주곡 13곡과 환상곡 2곡), 라흐마니노프 4곡, 사티 3곡, 리스트 67곡, 베토벤 21악장, 슈베르트 8곡, 슈만 48곡, 차이콥스키 《사계》 12곡으로 구성됩니다. 소나타는 악장별로, 소품과 변주곡은 각 작품 전체를 추천·보관합니다. 사용자 제공 제목·감정 점수·요약·감상 설명을 반영했습니다.

## 감정과 추천

감정의 순서·내부 키·한글 운영 명칭은 `src/data/emotions.js`가 단일 기준입니다. 화면에서 감동적인, 압도적인, 몽환적인, 부드러운, 평안한, 경쾌한, 힘찬, 긴장감 있는, 애잔한을 고릅니다. 느낌 선택은 최대 3개이며 동일 가중치입니다. 기분 선택은 `src/data/feelingSuggestions.js`의 별도 제품 정책으로 즉시 감정 키에 연결합니다. 느낌·기분은 각각 선택을 유지하고, 선택 초기화는 현재 탭의 선택만 지우며 탭을 바꾸지 않습니다. 선택한 느낌·기분을 다시 누르면 해제합니다. 해제 후 다시 선택하면 해당 조건으로 대표곡을 새로 추첨합니다. 추가 키워드·강도 선택 단계는 없습니다.

원점수 1~5를 `(s - 1) / 4`로 정규화합니다. 선택 감정의 평균 점수로 정렬하며, 선택 감정 중 하나 이상이 3 이상인 곡을 전체 추천 목록에 포함합니다. 후보가 부족하면 결과 개수를 줄입니다. 전체 후보 목록의 동점은 3 이상인 선택 감정 개수, 활성 개인화 유사도, 안정적인 ID 순서로 해소합니다. **느낌으로 시작하기**의 대표곡은 최고 평균 점수의 동점 후보 전체에서 무작위로 한 곡을 선택합니다. 단독 최고점 곡이 있으면 그 곡을 유지합니다. **기분에서 시작하기**의 대표곡은 최고 원점수 평균에서 1점 이내이고 연결된 두 감정이 각각 3 이상인 곡을 같은 확률로 추첨합니다. 기분별 직전 표시곡을 기억해 다음 추첨에서 제외하며, 후보가 하나뿐이면 그 곡을 사용합니다. 현재 기분별 후보는 기쁜·설레는 각 41곡, 차분한 49곡, 울적한 64곡, 답답한 30곡, 화나는 68곡입니다. 선택 해제·초기화·탭 전환에도 직전 기분 추천 기록을 유지하고 새로고침하면 초기화합니다. 느낌·기분을 선택할 때 다시 추첨하고 보관·해제·상세 조회 같은 일반 화면 갱신에는 대표곡을 유지합니다. 새로고침하면 선택부터 초기화됩니다. 기본 추천 화면은 개인화하지 않으며 내 취향 추천은 별도 전환으로 제공합니다.

## 보관함과 나의 취향

메인 화면은 대표곡 1개와 대표곡을 제외한 추천 순위 상위 최대 8곡을 가로 카드로 표시합니다. ‘추천곡 더 보기’는 대표곡을 포함한 전체 추천 목록으로 이동합니다. 전체 목록은 같은 추천 순서로 처음 20곡을 표시하고 ‘더 불러오기’로 다음 20곡씩 추가합니다. 이미 표시된 곡은 중복되지 않으며 마지막에는 불러오기 버튼을 숨깁니다. 키워드·기분·추천 방식이 바뀌거나 내 취향의 보관 기준이 바뀌면 표시 개수는 20곡부터 다시 시작합니다. 전체 목록에서 곡 상세·영상·보관 기능을 사용할 수 있으며 목록을 열거나 추가로 불러오는 동작은 대표곡을 다시 추첨하지 않습니다.

실제로 보관한 활성·평가 완료 곡만 중복 없이 사용합니다. 감정별 정규화 평균의 9차원 벡터가 취향 프로필입니다. 보관곡 1개부터 0이 아닌 프로필이 활성화되고, 3곡 미만이면 초기 취향으로 안내합니다. 감정 성향 지수는 프로필×100이며 차트는 0~100 고정 축입니다. 비율이나 확률이 아니며 합계가 100일 필요가 없습니다. 상위 감정 동점은 공동으로 표시합니다. 빈 보관함과 0벡터는 미형성 상태이며 차트·취향 추천을 만들지 않습니다.

내 취향 추천은 같은 9차원 벡터의 코사인 유사도로 정렬하고 이미 보관한 곡을 제외합니다. 모두 보관하면 빈 결과를 안내합니다. 키워드 추천으로 돌아갈 수 있으며 보관·해제 때와 새로고침 때 새 점수로 프로필을 계산합니다. 추천이나 상세 조회는 취향의 입력이 아닙니다. 취향 화면에는 현재 활성 목록의 곡 수와 작곡가를 안내합니다.

## 데이터 관리

2026-10-21 입력 102곡(슈만 36곡·리스트 66곡)을 모두 추가했습니다. 중복은 없습니다. 보류했던 메피스토 왈츠 No.4 S.216b는 2026-10-22 사용자 확인에 따라 별도 작품으로 등록했으며, 기존 catalogueNumber 필드에 `216b`를 보존합니다. 이 후속 추가에서도 기존 251개 작품의 개별 identity hash는 모두 유지됩니다. S.216b 후속 검증은 [등록 보고](docs/CATALOG_ADDITION_2026-10-22.md), 전체 ID·매핑·읽기 전용 검증은 [카탈로그 추가 보고](docs/CATALOG_ADDITION_2026-10-21.md)에 있습니다.

공연 찾기는 보관함·곡 상세에서 곡을 고르거나 화면에서 기존 곡 DB를 검색해 곡을 선택한 뒤, 지역·관람 기간을 설정해 KOPIS의 클래식 공연 목록을 조회합니다. 곡을 선택하기 전에는 목록·상세·OCR 요청을 보내지 않습니다. 같은 지역·기간은 초기 6시간 캐시를 재사용하고 ‘최신 정보로 새로고침’은 API를 다시 호출합니다. 곡을 바꿔도 기존 OCR 캐시는 작품 비교에 재사용하지만 새 곡의 검색은 버튼을 눌러야 시작합니다. 설정·운영 서버·배포 방식은 [KOPIS 설정 안내](docs/KOPIS_SETUP.md)에 정리했습니다. 자동 수집이나 예약 실행은 없습니다.

현재 직접 등록된 공연은 없습니다. 공연 찾기 화면은 선택한 곡의 작품 포함이 확인된 공연을 주 결과로 표시합니다. 음악 탐색의 감정 추천과 보관함 기반 곡 추천은 유지하되 감정 키워드는 공연 검색 조건으로 사용하지 않습니다.

현재 공연 검색은 **KOPIS 기준의 정확한 곡별 공연 검색 v1.0**입니다. 예정·진행 클래식 공연을 KOPIS ID로 중복 제거하고, 상세의 지역·기간을 OCR 전에 다시 확인합니다. 직접 등록한 프로그램이 자동 매칭을 대신하지 않습니다. 결과는 확인된 공연·확인이 더 필요한 공연·아직 확인하지 않은 후보로 안내합니다. 실제 PF302595·PF300769·예술의전당·롯데콘서트홀 검증과 미검증 항목, 수정 파일, 사용자 확인 순서는 [v1.0 완료 보고](docs/KOPIS_SEARCH_V1.md)에 있습니다.

- `src/data/concerts.js`: 직접 등록한 공연 목록은 비어 있으며, 작품 식별에는 기존 곡 데이터에서 파생한 정보를 사용합니다. 기존 곡 ID와 보관 기록은 그대로 사용합니다.
- `src/data/concertRecommendations.js`: 프로그램과 곡 평가의 기존 분석 함수는 유지합니다. 현재 공연 검색 화면은 감정·보관함 분석 점수 대신 선택한 곡의 작품 포함 근거를 보여줍니다. 음악 추천의 감정 점수와 보관함 추천은 계속 사용합니다.
- `src/data/concertTrackSearch.js`: 기존 곡 ID를 대상으로 한 곡명·작곡가·별칭·작품번호 검색. 검색 문자열 자체를 공연 프로그램이나 OCR 원문과 비교하지 않고 선택된 ID의 작품 정보를 서버에 전달합니다.
- `src/components/ConcertScreens.jsx`: 공연 카드·상세·확보한 프로그램·악장별 실제 점수·곡 상세·기존 미리듣기 연결. 작품 안내를 특정 악장 연주 확정으로 해석하지 않습니다.
- 한국 시간 티켓 오픈 전에는 ‘예매 오픈 예정’, 이후에는 공식 페이지 확인 안내를 표시합니다. 정확한 시작 시각을 아는 등록 공연은 시작 후 예정 목록에서 제외합니다. KOPIS의 기간 정보만 있는 공연은 회차 시간을 추정하지 않고 완료 상태·기간 종료를 기준으로 제외합니다. 좌석·판매 가능 상태를 추정하지 않습니다.
- KOPIS 검색은 기본 정보와 프로그램 확보를 분리합니다. 보관함의 ‘이 곡의 공연 찾기’는 실제 곡 ID를 서버로 전달합니다. 첫 검색에서 최대 10개 후보를 2개씩 점진적으로 확인하고, ‘더 찾아보기’ 한 번으로 다음 최대 10개를 확인합니다. 텍스트를 먼저 읽고 필요한 경우 소개 이미지 전체에 무료 Tesseract.js OCR을 적용합니다. 공연명·날짜·장소와 이미지의 관계, 프로그램 문맥, 작곡가·작품번호·곡번호·연주 범위를 검증한 일치 공연만 주 결과에 표시합니다. 후보별 대표 상태 8개와 조회 시도·처리 완료를 별도로 집계하며, 불완전한 자료는 불일치로 확정하지 않습니다. 이미지별 OCR 원문과 작품 추출 결과는 공연·이미지 URL·콘텐츠 해시를 기준으로 재사용합니다. 자세한 설정과 한계는 [프로그램 OCR 안내](docs/PROGRAM_OCR.md)를 참고하세요.

`npm test`는 곡·보관함·공연 추천과 검색 캐시·오류·페이지 처리, 프로그램 경계·작품번호, OCR 문맥·숫자 판독·부분 자료, 취소·중복 실행·상태 집계와 React DOM 흐름을 확인합니다. 실제 KOPIS의 PF302595에서는 이미지의 `F. Chopin / Ballade No. 1in G minor, Op. 23`을 OCR 원문에서 읽어 기존 `chopin-ballade-op23-no1`과 연결했습니다. 다른 곡으로 다시 비교할 때 이미지 OCR을 반복하지 않았고, PF300769의 시리즈 표기 충돌은 계속 확인 필요 상태로 유지했습니다. 실제 데이터와 자동 테스트의 범위는 [OCR 검증 기록](docs/PROGRAM_OCR.md)에 구분했습니다. 실브라우저 모바일 시각 검사는 아직 완료하지 못했습니다.

- `src/data/manualRatings.js`, `src/data/tchaikovskySeasons.js`: 확정 수동 평가 291곡·2,619개 점수. `ratingSource: manual`, `ratingVersion: manual-emotions-1`. 영문 표기는 작품 검색·프로그램 매칭에도 사용합니다.

대표 키워드는 3 이상인 감정 중 점수 상위 최대 3개이며 동점은 기준표 순서입니다. 전체 감정 점수는 상세에서 표시합니다. 미평가는 null로 두고 검토 대상으로 표시하며 추천과 취향 집계에서 제외합니다. EMMA 가져오기 도구는 참고 자료만 갱신하며 수동 평가를 변경하거나 곡을 자동 매칭하지 않습니다.

작곡가 이미지는 `composerImages`에서 공용 파일을 카드·상세·보관함에 공유합니다. 새 차이콥스키 초상은 [Wikimedia Commons의 CC0 이미지](https://commons.wikimedia.org/wiki/File:Portret_van_Pyotr_Ilyich_Tchaikovsky,_RP-F-F00667-AE.jpg)를 800×600 카드로 가공했습니다. 브람스 카드는 [C. Brasch의 초상 사진](https://commons.wikimedia.org/wiki/File:JohannesBrahms1.jpg)을 800×600으로 가공했습니다(Commons의 public domain 표기). 영상은 정확히 같은 작품·곡번호·악장에만 연결합니다. 전체 291곡에 사용자 제공 유튜브 영상·재생 구간을 연결했습니다. 신규 34곡의 링크는 사용자가 지정한 원래 곡 순서대로 반영했습니다. 영상·연주자·채널·종료 시각은 사용자 입력 그대로 반영했으며, 외부 메타데이터나 실제 청취로 별도 검증하지 않았습니다.

## 로컬 저장 마이그레이션

파가니니 변주곡 Op.35는 제1권·제2권을 독립된 곡 ID로 관리합니다. `bookNumber`로 권을 구분하며 검색·공연 연결에서도 다른 권을 함께 연결하지 않습니다. 이전 단일 항목 `brahms-variations-op35`는 활성 목록에서 제거했고, 해당 항목의 보관·좋아요는 새 권별 항목으로 자동 이전하지 않습니다.

`classic-atlas-track-reactions-v1`의 `listenAgain` 보관 상태와 `liked` 기록을 사용합니다. 데이터 버전 `manual-catalog-11`는 `classic-atlas-music-data-version`에 저장합니다. 기존 목록 버전의 ID와 보관·좋아요는 유지합니다. 키워드 선택은 현재 화면에서만 유지하고 새로고침하면 초기화합니다. 이전 `classic-atlas-music-selection-v1` 저장값은 앱 시작 시 제거합니다. 더 오래된 구 ID는 정확한 두 쇼팽 악장과 라흐마니노프 Op.23 No.5, 사티 짐노페디 No.1, 리스트 사랑의 꿈 No.3, 베토벤 월광 1·3악장·발트슈타인 1악장·열정 3악장을 명시적으로 연결합니다. 구 라흐마니노프 Op.3의 잘못된 곡번호는 추정 매칭하지 않습니다. 이미 삭제된 보관 기록을 복구하지는 않습니다. 다른 구 곡 참조는 제거하며 인증·다른 설정은 보존합니다.

선택값은 `classic-atlas-music-selection-v1`에 감정 키로 저장합니다. 유효한 키·현재 한글명은 유지하고 이전 편안한만 평안한으로 변환합니다. 따뜻한·장엄한 등으로 새 평가를 추정하지 않습니다. 최근 곡 키 `classic-atlas-recent-tracks-v1`이 있으면 ID 매핑·중복 제거를 적용합니다. 과거 취향·강도·추천 캐시 키만 폐기합니다. 정리된 보관곡이 있으면 한 번 안내하며 동일 버전 재실행은 추가 삭제를 하지 않습니다. `localStorage.clear()`는 사용하지 않습니다.

로그인·외부 음원 API·실제 공연 예매는 현재 범위에 포함되어 있지 않습니다. 기본 KOPIS 검색은 서버 전용 서비스키와 Node API를 사용하며 Supabase 검색은 별도 미리보기입니다. `.env.example`을 참고하고 개발은 `npm run dev`, Node 운영은 `npm run build` 후 `npm start`로 실행합니다. Vercel에서는 `api/index.js`와 `vercel.json`이 공연 API를 연결합니다. 기존 검색 배포 안내는 [Vercel 배포 안내](docs/KOPIS_SETUP.md#vercel-배포), DB 설정은 [미리보기 안내](docs/SUPABASE_CONCERT_PREVIEW.md)에 있습니다.

지역 선택은 공연 찾기에서 곡을 선택한 뒤 검색 조건 안에 표시합니다. 화면 폭에 맞는 선택 창에 전국·시도 목록을 3열 버튼으로 배치하며, 선택하면 창이 닫힙니다. 닫기 버튼·바깥 영역·Escape 키로도 닫을 수 있습니다. 기본값은 서울이며 선택은 `classic-atlas-concert-region-v1`에 별도로 저장해 탭 이동과 새로고침 후에도 유지합니다. 선택한 지역·기간은 검색 버튼을 누를 때만 조회 조건으로 적용합니다.
