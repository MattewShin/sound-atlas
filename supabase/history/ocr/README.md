# 폐기한 OCR 실행 SQL의 이력

CA-OCR-RETIRE-20261109-001. 과거 수동 진단·검증·자동화 및 v3 전제 SQL을 원문 그대로 `.sql.txt`로 보관합니다. 운영 실행/자동 migration 대상이 아닙니다. v3 원문은 격리 migration fixture 재구성에서만 읽습니다. 기존 `supabase/migrations`의 역사 기록은 변경하지 않았습니다.

최신 [폐기·공식 text 안내](../../../docs/OCR_RETIREMENT.md)를 따릅니다. 운영 적용은 아직 승인/실행되지 않았으며 별도 검토가 필요합니다.
